# Concepts

## RAG

- It enhances AI's ability to provide context-aware responses.
- Integrates real-time information retrieval.

## Multimodal AI

- Processes diverse data types.
- Allows for more interactive user experiences.

## Agentic AI

- Enables AI systems to autonomously execute tasks.
- Built by multiple AI Agents.

### AI Agent

- "Autonomous" entities designed for goal-directed task execution.
- "Autonomy", Task-Specificity, and Reactivity are the main characteristics.
- Other important concepts are Task Descomposition, Inter-Agent Communication, Memory and Reflection, and Orchestration.
- **Limitations**:
    - Lack of causal understanding.
    - Hallucinations.
    - Long-horizon planning and recovery.
- **Complexities**:
    - Cascade error.
    - Instability.
    - Scalability.
    - Explainability.

# Generative AI vs Agentic AI

- Generative AI:
    - It is reactive, since they wait for you to prompt and based on that, it will generate
    an output like text, image, code, audio, etc.
    - **Personal opinion**: you cannot create anything entirely original and new, since it only goes as far as it has learnt. It cannot view beyond what it has already seen.
- Agentic AI:
    - It is proactive. It starts with a prompt and it starts to pursuit an output through different actions that are decided, planned, and executed. Inbetween outputs can help it to learn and improve the final output.
    - Chain of thought reasoning to break down a complex task in several smaller tasks through an "internal monologue".
